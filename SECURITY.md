# Security Policy for BULT

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

BULT is a defensive, intelligence, and forensic tool. Vulnerabilities in parser routines (IQ file parsers, ELF/PE static analyzers, chemical formula parsers) or evidence integrity flaws are treated with high priority.

To report a vulnerability:
- Please do not open a public issue.
- Contact the maintainer: `black-210` via GitHub Security Advisories at `https://github.com/black-210/BULT/security/advisories`.
- Provide reproduction steps, sample fixtures (if testing a parser crash), and environment details.
- Responsible disclosure timeline is 90 days.
